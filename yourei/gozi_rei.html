35. 付録－誤字・校正リスト - web小説の書き方、ルール文書規則

例

警告ツールは万能ではなく、誤指摘もそれなりの確率で発生します。
当ツールは指摘の多さよりは、正確性を重視する傾向はありますが、それも完璧ではありません。

天地

いわゆる「前後入れ替わり」です。

ふいんき → ふんいき(雰囲気)
わたしく → わたくし)
ことろ → ところ
おそよ → およそ
カテーシー → カーテシー
チャハーン → チャーハン
ショテール → ショーテル

タイポグリセミア (Wikipedia) といい、そのまま読めてしまうため、肉眼で見落としがちです。
当ツールで有名なものに限って、いくつかはサポートしています。

誤変換

変換間違いで、文脈を見れば、明らかに間違っているケースがあります。
しかし文法上や単語そのものは間違っていないので、比較的ツールで拾いにくいです。
また作成者の知識上の時点で間違っていて、間違った変換を意図的に選んだ結果の誤字もあります。

を期に → を機に
例え天才でも → たとえ[仮令]天才でも
最もそれは → 尤もそれは

誤入力+誤変換

入力ミスやひらがなの時点で間違っている結果、変換が間違ってるケースです。

せんたっき → 洗濯機(せんたくき)
たいくかん/タイ区間 → 体育館(たいいくかん)
ざる負えない → ざるを得ない

一部の入力ソフトIMEではこの誤変換は「もしかして」機能などで補正候補が出る場合があります。
とはいえ、今でも誤字として残っているものも多いです。
この手のものは、ネット上でも有名で、主要なものはサポートをしています。

濁点、半濁点

「濁点(゛)の欠如」「濁点の付与」「濁点と半濁点(゜)の入れ違い」などです。

ありかとうございます → ありがとうございます
おはようごさいます → おはようごいざいます
脱いた人 → 脱いだ人
書いだんだけど →書いたんだけど
ジャカイモ → ジャガイモ
ペットポトル → ペットボトル

カナ入力者に多いといわれていますが、実際にはローマ字入力でもスマホのスワイプ入力でも発生します。
また、観測的に一文字目よりも、二文字目以降の頻度が高いです。
半濁点は、特にいえば「MSゴシック」など濁点と半濁点の区別がつきにくい環境で発生しやすいです。

末尾のktgdなどの濁点

ドック / ドッグ
バク / バグ
バック[back] / バッグ[bug]
ベット[bet] / ベッド[bed]

一方で、どちらも許容されているものもあります。
コボルト / コボルド
ハルバート / ハルバード
バンデット / バンデッド
これは表記が両方あったり、英語とドイツ語由来だったりと複数の要因があります。
これも、表記ゆれの原因ですので、そちらのオプションでチェックできます。

漢字ミス/意味

原因はいくつかありますが、見た目または意味が似ている、混同しやすい漢字はあります。

確率　＜―＞　確立
保障　＜―＞　保証
適性　＜―＞　適正
体勢　＜―＞　体制、態勢、大勢

漢字ミス/見た目

漢字を構成する要素が非常に似ていて、誤解しやすいものです。
特に部首や旁(つくり)が同じで、読みが同じだと発生しやすいです。

鍛治屋 → 鍛冶屋
候爵 → 侯爵
准決勝 → 準決勝
完壁 → 完璧
操縦土 → 操縦士
断未魔 → 断末魔
藤籠 → 籐籠
試験管　試験官
菅原　管原
荻原　萩原

比較的広くサポートしていますが、誤検出の可能性が上がりやすくなります。
しかし、またIMEで単語単位で正しく変換すれば発生しにくいので、遭遇ケースは低めです。
最近ではあまり見られませんが、手書き入力や古いOCRでは発生率が高めです。
手書きで書いて調べてコピペしてくると今でも発生すること自体はあります。

未登録単語

単語がそもそも未登録であったり、違う変換結果に引きずられて主に発生します。

即妃 → 側妃
御変換 → 誤変換

熟語、慣用表現の漢字選択

熟語や慣用表現により漢字がある程度決まっていることがあります。
ただし、作者個人の漢字の選択が優先されるケースでは、無視していい場合もあります。

直ならぬ → 徒ならぬ
癪に触る → 癪に障る
耳触り → 耳障り
ことある事に → 事ある毎に
固唾を飲む → 固唾を呑む
息を飲む → 息を呑む

四字熟語はだいたい正しい漢字があります。
ただし作者がワザと違う字を使っている(もじっている)場合などもあります。

固定概念 → 固定観念
心気一転 → 心機一転
危機一発 → 危機一髪
優々自適 → 悠々自適

動詞などでの漢字の選択

和語を中心に複数の漢字表記がある動詞や形容詞が多いです。
最終判断は作者によりますが、一般的であるものを示しています。

パンツを履く → パンツを穿く
嘘を付く → 嘘を吐く
底を着く → 底を突く
喉が乾く → 喉が渇く
皮鎧 → 革鎧

有名なものは採録され警告を表示します。

現代仮名遣い

仮名使いのうち、有名なものは警告されます。
当ツールは主に現代表現をターゲットに現代仮名遣いをメインに扱っています。
歴史的仮名遣いへの配慮は限定的です。

ひとつづつ → ひとつずつ
理解しずらい → 理解しづらい
被害者ずら → 被害者づら
づらす → ずらす
いかづち → いかずち
いいなづけ → いいなずけ
黒づくめ → 黒ずくめ
鯛ずくし → 鯛づくし
基ずく → 基づく
うっとおしい → うっとうしい

同音の漢字による書きかえ

当用漢字の当時、漢字を置き換えた政策のことです。
現代では多くの語彙がこの書きかえに従って書かれて一般化しています。
一方で定着せず、語彙によってその扱いはメディアでもバラバラです。
詳しくは「同音の漢字による書きかえ」をご覧ください。

馭者 → 御者
理窟 → 理屈
廻る→回る
壊瘍 ← 潰瘍
下剋上 ／ 下克上

誤用

誤用と一般的に信じられている表現もあります。
賛否あるケースもありますが、一部は採録されています。

犀が投げられた → 賽が投げられた
喝を入れる → 活を入れる/一喝する

印篭を渡す → 引導を渡す
ご教授ください → ご教示ください
初戦 → 緒戦 [確認表示]
知恵熱　[確認の表示]
動悸　[医学/誤用注意]

脱字

「誤字脱字」と一緒に語られる程度にはよくある現象です。

ありがとございます → ありがとうございます
ありがとうござます → ありがとうございます
魔力がります → 魔力があります

すべての組み合わせを拾うのは限界がありますが、気になったものは追加しています。
傾向としては、nの入力と母音まわりが欠落しやすいです。
また、やはり中間が欠落しやすい傾向があります。

衍字

衍字(えんじ)は、文字の重複のことです。

本をを拾う → 本を拾う
私はは人間です → 私は人間です
これににして → これにして
にになる → になる

特に助詞は拾えるものはツールで拾う方針ですが、ひらがなが連続していると難しいです。
誤検出とのバランスを見て、漢字やカタカナのと境界を検出して確度が高いものは警告します。
助詞以外でも常に発生しますが、そういうものは一律での検出が困難で、ほぼ未対応です。

若者言葉

違がくて → 違って
違うくて → 違って
違くない → 違わない
違がかった → 違った
ないくて → なくて

警告はしますが、必ず直さなければならないわけではありません。

表現規制

一部の、特に強い意味を持つ用語は[表現規制]といったタグを表示します。
直さなければらないわけではありませんが、校正者はほぼ指摘する項目です。
優先度の低いものは、緑表示のオプションの時だけ注意情報として表示します。

屠殺 → 解体　[表現規制]
